# 🏠 Global Airbnb Performance Dashboard


## 📊 Overview

This Power BI dashboard provides a comprehensive analysis of **global Airbnb performance** across 10 major cities worldwide. It covers listing trends, pricing, host ratings, reviews, and seasonality patterns.

---

## 📌 Key Metrics

| Metric | Value |
|--------|-------|
| 🏘️ Total Listings | 279,712 |
| 🌆 Cities Covered | 10 |

| 🏷️ Property Types | 144 |
| ⭐ Total Reviews | 5,373K |

---

## 📄 Dashboard Pages

### Page 1 – New Listing Trends (2008–2021)
- Tracks new listings over time by room type: Entire place, Private Room, Shared Room, Hotel Room
- Peak listings were in **2015**; growth stalled post-2019 due to **COVID-19**
- Airbnb became profitable in the **second half of 2016**

### Page 2 – City & Pricing Analysis
- **Listings by City**: Paris and New York lead with 55K+ listings
- **Average Price by Room Type**:
  - Hotel Room: $800
  - Entire Place: $673
  - Shared Room: $580
  - Private Room: $462
- **Ratings Table**: Mexico City and Cape Town are top-rated; Hong Kong and Istanbul score lowest

### Page 3 – Reviews, Seasonality & Trust
- **Reviews peak in December** (holiday travel); sharpest drop in April
- **Paris and Rome** dominate reviews from April–August (European summer travel)
- **New York** spikes in November–December (holiday season)
- **Trust signals**: 66.9% of hosts are verified with a profile photo
